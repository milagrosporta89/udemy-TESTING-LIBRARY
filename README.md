# A ciegas

Una práctica guiada para aprender a usar un lector de pantalla (NVDA, JAWS o VoiceOver) sin apoyo visual.

La persona elige su lector y apaga la pantalla. Desde ahí, una cortina negra tapa todo y bloquea el mouse, y solo
puede avanzar usando el teclado y la voz del lector. Son cuatro lecciones cortas:

1. Leer la página elemento por elemento.
2. Saltar por encabezados para encontrar una palabra secreta.
3. Encontrar y activar un botón entre varios.
4. Completar un formulario y entender sus mensajes de error.

## Cómo usarla

No hace falta instalar nada: abre `index.html` en el navegador. Si prefieres un servidor local:

```sh
npx serve .
```

Para salir de la pantalla negra, presiona `Escape` tres veces seguidas o usa el enlace
"Desactivar pantalla negra" que hay al final de cada lección.
